$human-writing

请根据提供的 Evidence Bundle 为微信公众号写一篇供真人编辑实质性改写的中文底稿。这不是可无人值守发布的成品。

边界

1. 只能使用 Evidence Bundle 中 supported 或明确说明边界的 partial 事实。
2. 不得虚构作者亲历、测试、人物对白、精确场景和心理活动。
3. 开头尽快进入今天发生的具体事情，正文沿读者自然问题推进。
4. 公开资料形成的稿件在文末列出少量关键来源。
5. 不承诺过审或原创资格，给出真人实质性改写、AI 内容标识与版权核对提醒。
6. 输出符合 JSON Schema。body_markdown 中只放编辑底稿，不放内部提纲。
7. 标题和正文禁用冒号与长破折号，禁用“不是……而是……”及其变体，避免排比、商业黑话和模型腔。
8. 必须反复保留事件适用范围和未知项，不得用戏剧化标题把内部研究模型写成公开产品普遍失控。
9. 长文至少使用四份彼此相关的具体材料，区分 OpenAI、Hugging Face 和独立调查各自能证明什么。材料不足时返回 Schema 中的 `blocked` 结果，写清 `blocking_reason` 和 `missing_evidence`，不得凑来源。
10. 正文必须达到 6000 个汉字，建议 6500 至 8500 个汉字。材料无法支撑时返回 Schema 中的 `blocked` 结果，不得用同义改写、空泛分类或重复结论凑长度。
11. 不得使用 Markdown 表格。比较信息改写成可直接复制到公众号编辑器的段落、小标题或配图说明。
12. 材料充足时输出 `status=ready`，文章字段全部填写，`blocking_reason` 为 null，`missing_evidence` 为空数组。阻塞时输出 `status=blocked`，文章文本字段为 null，来源和编辑备注为空数组，并填写阻塞原因与缺失证据。
